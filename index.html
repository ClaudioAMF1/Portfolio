01 / HEALTHTECH · LGPD · IA APLICADA

Gestão Clínica — VM Medicina

Sistema web interno da VM Medicina e Saúde Mental, clínica psiquiátrica em Brasília, onde atuo como tech lead. Pacientes, médicos, agenda com controle de conflitos de horário e financeiro, com a privacidade dos pacientes tratada como requisito de arquitetura, não como detalhe.

Cada perfil (administrador, médico, recepção) só vê o que precisa: a regra mora no backend, em cada rota. Todo acesso a dado pessoal fica numa trilha de auditoria, e a base analítica é anonimizada com pseudônimos HMAC-SHA256 e medida por k-anonimato antes de alimentar qualquer modelo.

backend
FastAPI async + SQLAlchemy + Alembic
frontend
React 18 + TypeScript
privacidade
RBAC por perfil + trilha de auditoria (LGPD)
dados
anonimização HMAC-SHA256 + k-anonimato
IA
modelo de faltas (scikit-learn) + chatbot de acolhimento com barreira de crise
qualidade
34 testes automatizados (pytest)

02 / FINTECH · AUTOMAÇÃO · CLIENTE REAL

CAMF — Contas a Receber

Aplicação full-stack que transforma PDFs de boletos Sicoob em uma base de contas a receber auditável para a CAMF Construtora. Cada boleto é conferido contra a própria linha digitável: dígitos verificadores módulo 10 e 11, valor e fator de vencimento, já com a virada FEBRABAN de 2025.

Nada é aceito em silêncio: qualquer divergência entre o texto impresso e a linha digitável manda o boleto para revisão manual, com o motivo registrado.

extração
pdfplumber + regex, dois layouts de página
validação
linha digitável como fonte da verdade
integridade
deduplicação SHA-256, soft delete, auditoria append-only
relatórios
XLSX, CSV e PDF respeitando os filtros da tela
deploy
Docker → Render, API e frontend num serviço só

04 / CIVIC TECH · MOBILE · DADOS ABERTOS

LegiTrack — Projetos de Lei

App para qualquer cidadão acompanhar a tramitação de Projetos de Lei na Câmara dos Deputados. Um worker consulta periodicamente a API de dados abertos da Câmara, atualiza a base e avisa quem favoritou cada projeto quando há uma nova movimentação.

O feed é filtrado pelas áreas de interesse de cada pessoa (saúde, tecnologia, economia…), com busca em tempo real e a linha do tempo de cada proposição. Desenvolvido em dupla.

Flutter (Material 3)
API
Flask + Swagger (Flasgger)
worker
coleta periódica da API da Câmara + notificações
banco
PostgreSQL + SQLAlchemy
auth

07 / PESQUISA · SEGURANÇA · PRIVACIDADE · EM ANDAMENTO

Quem mais está dentro do aplicativo?

Meu TCC investiga se aplicativos móveis oficiais do governo brasileiro, inclusive os que tratam dados de saúde, biometria e previdência, embarcam SDKs de rastreamento de terceiros que enviam identificadores de cidadãos para infraestrutura no exterior. E compara com aplicativos comerciais pareados por categoria e porte, a linha de base que estudos anteriores não tinham.

O cidadão pode trocar de app de banco; não pode trocar de INSS. Por isso o trabalho também mede a própria régua: se ferramentas diferentes de detecção concordam sobre o mesmo APK.

corpus
396 apps de 71 órgãos públicos, nas três esferas
dado sensível
152 apps (38,4%) tratam dados do Art. 11 da LGPD
primeiro achado
0 de 396 apps de governo exibem anúncio, contra 33,2% do controle comercial
instrumentos
MobSF, Androguard e assinaturas do Exodus, APKs via AndroZoo
estatística
